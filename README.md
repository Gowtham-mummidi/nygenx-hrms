# NYGENX HRMS - Next-Gen Human Resource Management System

The unified intelligence operating system for next-generation workforce management, developed for **[NYGENX Technologies](https://www.nygenx.com/)**.

## Overview
NYGENX HRMS is an enterprise-grade HR and workforce platform powering:
- **Core HR & Workforce Operations:** Employee directory, department hierarchy, attendance & biometric tracking, leaves, payouts, and performance.
- **Talent Acquisition & Candidate Portal:** Multi-round recruitment workflows, ATS scoring, candidate self-service portal, automated offer release, and background document verification.
- **Hardware & Asset Intelligence:** Laptop allocation, QR/Barcode asset tagging, seating mapping, and automated lid-closed checkout.
- **Enterprise Services:** Insurance enrollment, service requests, complaints, internal parking passes, and project management.

## Tech Stack
- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS + Radix UI + Lucide React
- **Backend / DB:** Supabase (PostgreSQL, Auth, RLS policies, Storage)
- **Deployment:** GitHub Pages / Netlify / Node SMTP daemon
